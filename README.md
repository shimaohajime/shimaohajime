# Hajime Shimao — academic homepage

This repository contains the static source for Hajime Shimao's academic homepage. The site intentionally uses a plain, single-page format similar to the former Google Site.

## Publishing with GitHub Pages

In the repository on GitHub, open **Settings → Pages**. Under **Build and deployment**, choose **Deploy from a branch**, select the `main` branch and the `/(root)` folder, then save. The site will be available at:

`https://shimaohajime.github.io/shimaohajime/`

The current CV is in `assets/pdf/Hajime_Shimao_CV.pdf`. Replace that file when updating the CV, keeping the filename unchanged so the site link remains valid.
